# Modern code release history — MockDesign integration onward

The modern integration started at **v0.4.2**; its changelogs are retained **once per release** here. v0.5.1 eliminates the separate ClassicApp UI, exposes legacy domain operations inside one modern interface, restores branding and separates historical documents. Source-level tests are not proof of Expo Go runtime stability.

v0.5.2 adds persistent status checkboxes, grouped task tags, safe-area native notifications, status routing and card-aging rules, accent selection and standardized disclosure controls.

v0.5.4 fixes the duplicated Task configuration drawer key and increases the contrast and size of embedded PROJECTS lettering; no dependency changes.
