# Unslop audit — Kanban v0.3.12

Reference: original Unslop skill by Damir Sokolovsky, CC BY 4.0 (bundled at `.opencode/skills/unslop/SKILL.md`).

**Direction (five lines):**
- Product: purposeful local-first project management with concrete task, status and release context.
- Character: reserved, fast, precise.
- World: quiet engineering/operations workbench.
- Memorable moment: move a clear card between workflow columns without losing its task metadata.
- Signature: user-selected monochrome Niyarvo accent and semantic status indicators, not spectacle.

**Before audit (ordered):**
- Spacing: tall descriptions and footer repository text made dense 73-task boards costly to scan.
- Color: primary chips competed for attention; retain only meaningful priority/overdue indicators.
- Icons: meaningful card metadata was mostly plain text instead of compact indicators.
- Copy: card IDs and titles repeated unnecessary repository descriptive copy.
- Typography: task title should lead with one restrained weight; metadata smaller and muted.
- Layout: independent column heights already fixed in v0.3.9 and preserved.
- Details: labels, comments, attachment and checklist signals missing from compact board presentation.
- Visuals: no external imagery required; the cards are the real product content.
- Motion: preserve existing hold-to-drag and avoid new decorative transitions.

**After:** Card content is tighter, labels/checks/assignee are visible, per-board descriptions opt-in, actions in a minimal contextual sheet, filters grouped with quiet controls. No new gradients, glows, mascots, noisy status badges or dependency changes. Actual screen visual QA remains pending on user device.
