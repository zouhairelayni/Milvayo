# v0.5.33 mobile browser / dependency color hotfix

This ZIP is a guarded source overlay for the installed v0.5.33 checkout. It keeps desktop mode on desktop browsers or when requested, while ordinary mobile Web adopts the Android-like mobile shell. Timeline dependency curves regain their seven-color palette.

Extract at project root, dry-run and apply using the commands in `docs/CHG-NP-0.5.33-WEB-MOBILE-LINK-COLORS.md`. All changes are preflighted before writing, and the tool refuses an unfamiliar source shape.
