# Unslop audit — v0.3.10 Automation Studio

**Product:** local-first project, Gantt and Kanban management for people coordinating delivery.  
**Character:** calm, exact, dependable.  
**World:** planning instruments and quiet technical workbenches.  
**Moments:** rule editor and execution history — no extraneous illustration.  
**Signature:** Niyarvo selected accent, neutral surfaces, precise task status labels.

## Nine passes and observed result

1. **Spacing:** new automation editor uses 8/12/16 spacing, 44px controls, and separate setting groups. Mobile wraps options rather than squeezing rows.
2. **Color:** graphite surfaces and one accent for selected conditions. Warning/error use semantic red. No gradient or glow.
3. **Icons:** avoids decorative icons in new editor; shared app Ionicons preserved.
4. **Copy:** trigger and action labels use operational terms. Due checks explicitly described as user-run, not a background service.
5. **Typography:** 12–17px hierarchy, appropriate label weight; still needs native font rendering QA.
6. **Layout:** editor and list/history separated into panels, with bounded history scroll; new board buttons appear alongside board selection.
7. **Details:** enabled states, input limits, errors, and priority/board scoping visible.
8. **Visuals:** none added; the content is a technical workflow form.
9. **Motion:** no new animations; retains existing card drag gestures.

**Unverified:** real Android portrait density, keyboard appearance with input focus, screen reader controls, and Web screenshot comparison. This is a focused feature UI review, **not a whole-app aesthetic redesign**.
