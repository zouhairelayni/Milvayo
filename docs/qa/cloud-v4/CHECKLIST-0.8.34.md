# Check for 0.8.34: an open Canvas and the other person's changes (phone + web)

Status of this version: Planner-tested only. Nothing counts as working until you have seen it on both devices.

1. **Both open.** Open the same Canvas on the phone and on the web and leave both open.
2. **Add on the web.** On the web add a note. On the phone (without closing the Canvas) wait up to about a minute. The note should appear by itself.
3. **Move on the web.** Move that note on the web. The phone should show the new position by itself.
4. **Edit on the phone.** On the phone, move a different note. Wait up to a minute. On the web check: the first note is still where you moved it, nothing disappeared.
5. **Both at once.** Add one note on the phone and one on the web within a few seconds. After a minute both notes exist on both devices.
6. **Compare.** Run "Compare with cloud" on both. Both should say "the same records". Send me the text if either says DIFFERENT.
7. **Message check.** If at any time you see "Canvas changed; reopen it", write down what you did just before. That means the screen was out of date and it refused to overwrite; the open Canvas should now update by itself, so this message should be rare.

Write down for each step: as described, not as described, or unclear, and what you saw.
