# Check for 0.8.42: new boards, deleting boards, and the new sign-in screen (two DIFFERENT accounts)

Status of this version: Planner-tested only. Nothing counts as working until you have seen it on both devices.

1. Sign-in screen: Settings > Cloud (signed out). Does it look like a normal sign-in card (Email, Password, one choice, one Sign in button), not a terminal? Is "Connection details" folded away? Does it fit a phone screen? Signing in still works, in both choices.
2. A creates a new Canvas board and puts two notes and a connector on it. Within about a minute B sees the board with its notes and connector. The Cloud screen on A does NOT say "not shared yet".
3. A archives that board, then deletes it. B sees the board gone, with its notes. The first board is untouched on both.
4. Try deleting a board that is not archived: the app should refuse ("Archive the Canvas before deleting it") as before.
5. (Optional) A board with more than 99 notes: delete it. If the cloud refuses, the message says to delete some notes first; delete some, then delete the board again.
6. A creates a board while B is offline; B comes online later and sees it.

Write down for each step: as described, not as described, or unclear, and what you saw. For step 1 a screenshot helps.
