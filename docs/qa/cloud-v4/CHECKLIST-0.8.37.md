# Check for 0.8.37: who else is here (two DIFFERENT accounts)

Status of this version: no code change; Server-tested rules and Planner-tested client only. Nothing counts as working until you have seen it on both devices.

Use two different accounts (A on the phone, B on the web). The same account on both will show nothing: that is on purpose.

1. **Same task.** A and B both open the same task. Within about 30 seconds each shows "1 other member(s) viewing".
2. **Editing.** B starts editing the task description. A shows "Another member is currently editing this task".
3. **Different task.** B opens another task. A no longer shows anything on the first task.
4. **Leave.** B closes the task. A's line disappears within about 30 seconds.
5. **Lost connection.** B turns off Wi-Fi/data while the task is open. A's line should disappear within a minute or two (at most 5 minutes). Write down how long it took.
6. **Discussion.** Both open the same discussion; B types a message. A shows "Another member is typing".

Write down for each step: as described, not as described, or unclear, and what you saw.
