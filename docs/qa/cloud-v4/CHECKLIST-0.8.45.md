# Check for 0.8.45: risks, work breakdown, budget lines, documents (two DIFFERENT accounts)

Status of this version: Planner-tested only. Nothing counts as working until you have seen it on both devices.

1. A adds a risk and edits its text. Within about a minute B sees the risk and the new text. The Cloud screen on A does NOT say "not shared yet". B deletes the risk (manager) and A sees it gone.
2. A adds three budget lines, then deletes the first one. B sees two lines. B changes the planned amount of one; A sees it.
3. A adds a work element with a sub-element under it. B sees both. A deletes both. B sees them gone.
4. A and B both open the SAME project document (for example the Charter) and each types in a DIFFERENT box at the same time. Afterwards both devices show BOTH texts.
5. A contributor (not a manager) tries to set a document to Approved: it is refused with a message about manager level. A manager can do it.
6. A swaps two risks (changes their order). This is NOT shared yet by design: the Cloud screen says so, nothing breaks.
7. A new risk or budget line appears at the END of the list on both devices (even if A put it at the top). That is expected.

Write down for each step: as described, not as described, or unclear, and what you saw.
