# Check for 0.8.44: Canvas comments (two DIFFERENT accounts)

Status of this version: Planner-tested only. Nothing counts as working until you have seen it on both devices.

1. A starts a comment on a note. Within about a minute B sees the comment on that note. The Cloud screen on A does NOT say "not shared yet".
2. B replies. A sees the reply. A resolves the thread. B sees it resolved.
3. A and B both reply to the SAME comment at the same time (tap Send together). Afterwards both devices show BOTH replies and neither asks you to choose.
4. A deletes the note that has a comment. B sees the note and its comment gone.
5. (Only if you have a view-only or comment-only account) a comment-only person can start a comment and reply but cannot move or edit notes. A view-only person cannot comment.

Write down for each step: as described, not as described, or unclear, and what you saw.
