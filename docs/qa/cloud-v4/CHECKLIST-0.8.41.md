# Check for 0.8.41: rename and archive a Canvas board (two DIFFERENT accounts)

Status of this version: Planner-tested only. Nothing counts as working until you have seen it on both devices.

1. A renames a Canvas board. Within about a minute B sees the new name. The Cloud screen on A does NOT say "not shared yet".
2. A archives the board. B sees it archived. A un-archives it; B sees it active again. The notes on the board are all still there on both.
3. A and B rename the same board at the same moment. One side gets "needs your review"; "Keep cloud version" settles it and both show the same name.
