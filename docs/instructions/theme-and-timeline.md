# Theme and Timeline controls

Theme and accent changes update Milvayo immediately. They do not change the installed native launcher icon automatically. When ready, open Settings → Apply launcher icon and confirm; Android may close the app to refresh its entry. Cancel to continue working. Expo Go cannot change its own icon. A new installed build is required for the 0.6.3 native fixes.

System follows the operating system appearance. Timeline supports two-finger pinch and explicit Zoom in/Zoom out controls. Zoom changes only date density; it never changes task dates. Moving shifts both dates; resizing changes duration with the opposite end fixed.

On Timeline, the magnifier controls overlay the chart’s upper-right corner. Their icons are 18px with 44px touch targets; desktop users can focus them with Tab or use their tooltips. Days, Weeks and Months change density while keeping the focal date where bounds allow. First task and Today remain explicit navigation controls. Date text keeps its proportions during a pinch.

Projects supports finding a project by name or code and showing the next 20 results. This only changes the visible list; it does not archive or remove projects.
