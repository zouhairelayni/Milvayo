# First-run tour

In the redesign app, open **More → Take the tour**. Existing installations keep their data and do not open the tour automatically. Empty new installations open it after the workspace becomes ready.

Swipe or use Next through Board, Timeline and release checks, then choose a starter and name your new project. Skip leaves existing projects and tool settings unchanged. Android Back, the visible Back button and web Escape return through the flow; Back/Escape from the first slide skips.

- Board and Blank open Board with Sprints/Releases/Testing hidden for the new project.
- Timeline opens Timeline with those same optional tools hidden.
- Sprints opens Sprints with the normal lean project tools enabled.

All starters create an ordinary empty project. Existing projects remain. Enable tools later from More → Manage tools. A failed creation keeps the draft for retry; waiting for the result prevents duplicate submissions.

No new packages, schema migration or build is required for these JavaScript changes. Continue using your existing Metro/Fast Refresh workflow rooted at `~/Milvayo/redesign`. Native/device acceptance is pending. Do not clear data or reinstall to test the first-run behavior. See `docs/qa/redesign-063/FIRST-RUN-TOUR-INTEGRATION.md` for checks and limitations.
